# Media Assets

Put the final Google Play visual assets here.

## Required Folders

- `app_icon/` - final exported 512x512 store icon
- `feature_graphic/` - Google Play feature graphic
- `phone_screenshots/` - phone screenshots for store listing
- `video/` - promo video files, captions, and editing notes

## Practical Recommendation

Use real in-app captures from the Android release build. Avoid mock-only screenshots unless they are used as clearly designed promotional images outside the core screenshot set.
