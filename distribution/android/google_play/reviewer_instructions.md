# Google Play Reviewer Access Instructions

## Instruction title

Full app access instructions for Google Play review

## Instructions

The app does not require a paid subscription, invite code, VPN, or location-specific access.

Reviewers can create a fresh test workspace directly in the app:

1. Open the app.
2. Select the **Sign up** tab.
3. Enter any review email address that Google Play can access.
4. Use a test password that meets the form requirements.
5. Enter:
   - Full name: `Google Play Reviewer`
   - Position: `Chief Engineer`
   - Company name: `Google Play Review Workspace`
6. Submit the sign-up form.
7. If an email confirmation message is required, confirm the email and return to the app.
8. Sign in with the same email and password.

After signing in, the reviewer will see the company workspace. To access the main app sections:

1. On the main workspace screen, create a new task using the new task action.
2. Open the created task and activate it. New infrastructure records can then be linked to this active task.
3. Open **Infrastructure Map** to review the map, infrastructure objects, route filters, map layers, and location-based features. If Android asks for location permission, allow it to test current-location behavior, or deny it to continue testing the rest of the app.
4. Open **Muff Notebook** to create and edit fiber closure records.
5. Open **Network Cabinet** to create and edit cabinet, cable, port, and fiber records.
6. Open the cable/routes section from the workspace or infrastructure tools to review cable line route creation and editing.
7. Open **Team** from the top actions to review employee and invite management.
8. Open **Profile** from the top actions to review the user profile, company role, and position editor.
9. Use **Refresh** to reload synchronized company data.
10. Use **Sign out** when testing is complete.

Notes for review:

- The app is a B2B infrastructure management tool for telecom and network operations teams.
- Reviewers may use sample/non-production data such as test cabinet names, test closure names, mock addresses, and map points.
- The first registered user in a new company workspace receives owner-level access and can reach all currently available sections.
- If a reviewer account already exists, use the **Sign in** tab or the password reset flow.
