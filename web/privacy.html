Privacy Policy

Net Infra SaaS. Last updated: May 4, 2026.

This policy explains what data Net Infra SaaS processes, why the data is used, and how users can contact support about privacy-related questions.

1. Data We Process

The application may process the following categories of data:

  • account data: work email, password, name, position, company, and user role;
  • company workspace data: projects, tasks, assigned employees, work statuses, and service notes;
  • technical network infrastructure data: cabinets, splice points, cable lines, routes, addresses, object coordinates, and related records;
  • device location data, if the user grants location access for map and infrastructure-object features;
  • technical session data required for sign-in, authorization, and data synchronization.

2. How Data Is Used

Data is used to:

  • register users, sign users in, recover access, and manage user sessions;
  • create and maintain a company workspace;
  • manage network cabinets, splice points, cable lines, tasks, and other infrastructure records;
  • display objects on a map and save coordinates for infrastructure records;
  • synchronize data between employees of the same company;
  • support security, access control, and error diagnostics.

3. Location Data

The application requests approximate or precise location access only for features related to maps and infrastructure-object records. Location data is used after the user grants permission. Users can disable location access in their device settings.

4. Storage and Processing

Application data is stored and synchronized through Supabase cloud infrastructure. Access to workspace data is limited to users of the relevant company and their roles. The application uses a network connection for authorization, loading, saving, and synchronization.

5. Data Sharing

We do not sell users' personal data. Data may be processed by infrastructure providers required to operate the application, including Supabase, to the extent needed for authentication, storage, and synchronization. Data may also be disclosed when required by law.

6. Retention and Deletion

Data is stored while the account, company, or related work records are needed to use the application. A user or company representative may request account or related data deletion by contacting support.

7. Security

We use organizational and technical measures to protect data, including user authorization and company-level access separation. However, no method of transmission or storage can be guaranteed to be completely secure.

8. Children

Net Infra SaaS is designed for company workflows and network infrastructure specialists. The application is not intended for children and is not directed at collecting data from children under 13.

9. Policy Changes

We may update this policy when application features, legal requirements, or data-processing practices change. The current version is published on this page.
